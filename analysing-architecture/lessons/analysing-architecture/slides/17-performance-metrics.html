Performance Metrics

⏱

Response Time

Time from request to response

Measured in milliseconds
Target: < 200ms for web APIs
📈

Throughput

Number of requests processed per unit time

Measured in TPS / RPS
Target depends on system capacity
⚠

Error Rate

Percentage of failed requests

Ratio of errors to total requests
Target: < 0.1% under normal load
🔌

Latency

Time for data to travel through the system

Measured in milliseconds
Affected by network distance & routing
