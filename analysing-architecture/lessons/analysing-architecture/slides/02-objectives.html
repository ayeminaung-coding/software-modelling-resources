Learning Objectives

By the end of this lesson, you will be able to:

1. Understand Analysis Purpose

Understand why and what we analyse in software architecture

2. Apply Use Case Analysis

Apply use case analysis through prototyping and simulation

3. Perform Quality Attribute Analysis

4. Conduct Trade-off Analysis

Conduct trade-off analysis between competing quality attributes

5. Evaluate with Cost-Benefit Analysis

Evaluate architecture through cost-benefit analysis
