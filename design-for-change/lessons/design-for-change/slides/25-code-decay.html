Code Decay

Code Decay: When the code/implementation is not consistent with the design

Makes code harder to change

Can lead to defects

What to do about code decay?

  • ✓ Prevent code decay — communicate design to developers
  • ✓ Check consistency — verify changes align with design
  • ✓ Code reviews — quality gate before code is committed
  • ✓ Fix code decay — refactor code to match design
  • ✓ Refactoring sprints — dedicated time to improve consistency

Code Review Process

Developer makes change → Another developer reviews → Checks for defects AND design violations → Comments for fixes → Code committed after approval
