Strategies to Localize Changes

1. Limit Possible Options

Restricting options reduces the effect of changes.

  • Use enums instead of free text
  • Defined interfaces instead of ad-hoc calls
  • Contracts over conventions

2. Hide Information

Quarantine changes within the module:

  • Decompose responsibilities into smaller pieces
  • Choose which parts are private, which are public
  • Make public parts available only through specified interfaces
