Types of Changes

➕

Adding Functionality

New features, new modules, new capabilities that extend the system.

e.g., Add mobile receipt scanning
✎

Modifying Behavior

Changing existing logic, updating business rules, fixing bugs.

e.g., Change tax calculation rules
⚙

Platform Changes

Upgrading frameworks, changing databases, new deployment targets.

e.g., Migrate from MySQL to PostgreSQL
🔗

Integration Changes

Connecting to external systems, APIs, or third-party services.

e.g., Add Booking.com expense import

Each type of change has a different ripple pattern — good design anticipates all of them
