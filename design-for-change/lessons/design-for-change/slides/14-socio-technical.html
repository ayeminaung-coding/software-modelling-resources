Socio-Technical Consistency

What happens when required coordination doesn't happen?

⚠

Poor Design

  • System still works, but less well
  • Performance degrades
  • Features conflict
  • Technical debt accumulates
✘

Defects

  • System breaks
  • Changes from one team break another team's code
  • Integration failures
  • Production incidents

You can observe this empirically by comparing module dependencies (technical) against team communication patterns (social). Divergences correlate with defects.
