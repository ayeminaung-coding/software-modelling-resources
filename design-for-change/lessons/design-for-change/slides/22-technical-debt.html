Technical Debt

⚠

The Metaphor

Sometimes you know you've broken the design, but do it anyway due to schedule pressure. You've deferred work to the future.

⚙

The Consequence

Code passes tests but violates design principles that enable extensibility and maintainability.

📈

The Interest

Like financial debt, technical debt accumulates interest. Changes get progressively more expensive over time.

🛠

The Plan

Need a plan to pay down debt. Schedule refactoring work to make code consistent with design again.
