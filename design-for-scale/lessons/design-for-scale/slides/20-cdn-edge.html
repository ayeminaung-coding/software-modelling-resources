CDN and Edge Computing

Content Delivery Network (CDN)

Distributed network of servers that cache content closer to users

  • Static assets (images, CSS, JS)
  • Video streaming
  • API response caching
  • DDoS protection

Popular CDNs

CloudFlare, AWS CloudFront, Akamai, Fastly, Azure CDN

Edge Computing

Run code at the edge, close to users

  • Compute at CDN nodes
  • Personalization
  • A/B testing
  • Request routing

Edge Platforms

CloudFlare Workers, AWS Lambda@Edge, Vercel Edge, Deno Deploy
