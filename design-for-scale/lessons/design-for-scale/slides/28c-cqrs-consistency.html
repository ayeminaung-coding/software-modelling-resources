CQRS: Handling Eventual Consistency

Consistency Challenges

The Problem

User creates order → immediately views orders → new order not visible yet!

Sync delay: 10ms - 2s typical

Solutions

1. Optimistic UI Updates

Update UI immediately, sync in background

2. Read-Your-Writes

Query write DB for recent user changes

3. Polling/WebSocket

Wait for read model to update

4. Version Vectors

Track expected version, retry if stale

Implementation Example

// Projector Example (Node.js)
class OrderProjector {
  async handle(event) {
    switch(event.type) {
      case 'OrderCreated':
        await this.readDb.insert({
          id: event.orderId,
          customer: event.customerName,
          total: event.total,
          status: 'pending',
          createdAt: event.timestamp
        });
        break;

      case 'OrderShipped':
        await this.readDb.update(
          { id: event.orderId },
          { status: 'shipped',
            trackingNo: event.trackingNo }
        );
        break;
    }
  }
}
Idempotency: Projectors must handle duplicate events! Use event ID to detect replays.
