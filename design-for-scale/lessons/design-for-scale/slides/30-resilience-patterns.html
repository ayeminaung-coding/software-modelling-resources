Resilience Patterns

Circuit Breaker

🔌

Stop calling failing services. States: Closed → Open → Half-Open

if (failures > threshold)
  circuit.open()
  return fallback

Retry with Backoff

🔄

Retry failed requests with exponential delay

delay = base * 2^attempt
// 1s, 2s, 4s, 8s...

Bulkhead

🚢

Isolate failures to prevent cascade. Limit concurrent calls per service.

pool.payments = 10
pool.inventory = 20

Timeout

Set maximum wait time for external calls. Fail fast rather than hang.

Always set timeouts

Fallback

Provide degraded functionality when primary fails. Cache, default, or alternative.

Graceful degradation
Tools: Resilience4j (Java), Polly (.NET), Hystrix (legacy), Envoy proxy
