Database Scaling Strategies

📖

Read Replicas

Copy data to read-only replicas to distribute read load

  • Async replication
  • Eventual consistency
  • Easy to implement
🔀

Sharding

Partition data across multiple database instances

  • Horizontal partitioning
  • Shard key selection
  • Complex queries
📊

Partitioning

Split tables within single DB by range or list

  • Date-based splits
  • Single instance
  • Easier management
