Vertical Scaling (Scale Up)

How It Works

  • Upgrade existing hardware
  • Add more CPU cores
  • Increase RAM capacity
  • Use faster storage (SSD/NVMe)
  • Upgrade network bandwidth

Best For:

Databases, legacy applications, quick fixes

Advantages

  • Simple implementation
  • No code changes
  • No distributed complexity
  • Lower initial cost

Disadvantages

  • Hardware limits
  • Single point of failure
  • Downtime for upgrades
  • Expensive at scale
Limitation: There's always a ceiling - the most powerful single machine has finite resources.
