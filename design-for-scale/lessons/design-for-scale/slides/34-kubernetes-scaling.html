Kubernetes for Scaling

Scaling Mechanisms

Horizontal Pod Autoscaler (HPA)

Scale pods based on CPU/memory metrics or custom metrics

spec:
  minReplicas: 2
  maxReplicas: 10
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        averageUtilization: 70

Vertical Pod Autoscaler (VPA)

Adjust CPU/memory requests automatically

Cluster Autoscaler

Add/remove nodes based on pod scheduling needs

Key Features for Scale

  • Service Discovery: Automatic DNS for services
  • Load Balancing: Distribute traffic across pods
  • Rolling Updates: Zero-downtime deployments
  • Self-Healing: Restart failed containers
  • Resource Limits: Prevent noisy neighbors

KEDA

Kubernetes Event-Driven Autoscaling. Scale based on external events (Kafka lag, queue depth, etc.)
