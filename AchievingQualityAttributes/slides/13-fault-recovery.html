Fault Recovery Tactics

Tactic Description Typical Downtime
Active Redundancy (Hot) All replicas process in parallel Near zero
Passive Redundancy (Warm) Standby syncs periodically State sync + switch time
Cold Spare Backup activated on failure Boot + state restore time
Checkpoint/Rollback Periodic state snapshots Restore to checkpoint time

Trade-off: Cost vs. Recovery Time

Warm
