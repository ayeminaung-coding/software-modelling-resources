Resource Arbitration Tactics

Determine how to resolve contention for shared resources

Scheduling Policy Description Use Case
FIFO First In, First Out Equal priority requests, message queues
Fixed Priority Static priority assignment Critical vs. normal traffic (VIP users)
Dynamic Priority Priority based on deadline/context Real-time systems, SLA guarantees
Fair Scheduling Equal resource allocation Multi-tenant systems, shared clusters

Rate Limiting Strategies

  • Token Bucket: Allows bursts up to bucket size
  • Sliding Window: Smooth rate enforcement
  • Leaky Bucket: Constant output rate

Modern Implementations

  • Kubernetes QoS classes
  • API Gateway rate limits
  • Priority queues (SQS FIFO)
  • Load shedding under pressure

Load Shedding: When overwhelmed, intentionally drop low-priority requests to maintain quality of service for critical operations. Better to serve some users well than all users poorly.
