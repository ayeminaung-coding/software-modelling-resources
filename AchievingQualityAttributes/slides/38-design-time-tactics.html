Design-time Usability Tactics

Enable usability through architectural decisions

Separate UI from Logic

  • MVC, MVP, MVVM patterns
  • Backend for Frontend (BFF)
  • GraphQL for flexible queries
  • Independent UI development

Allows UI changes without backend changes

Design Systems

  • Consistent component library
  • Design tokens (colors, spacing)
  • Shared patterns and behaviors
  • Documentation and guidelines

Examples: Material UI, Tailwind, Chakra

Accessibility by Design

  • WCAG 2.2 compliance
  • Semantic HTML structure
  • Keyboard navigation
  • Screen reader support
  • Color contrast ratios

Internationalization (i18n)

  • Externalized strings
  • RTL layout support
  • Date/number formatting
  • Cultural considerations

Key Principle: Design for the extremes and the middle will take care of itself. Designing for accessibility benefits all users, not just those with disabilities.
