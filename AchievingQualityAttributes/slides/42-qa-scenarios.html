Quality Attribute Scenarios

A structured way to specify and measure quality requirements

Scenario Template

Source Who or what generates the stimulus (user, external system, internal component)
Stimulus The event or condition that affects the system
Artifact What part of the system is affected
Environment The system state when the stimulus occurs (normal, peak, degraded)
Response How the system should respond to the stimulus
Response Measure How to measure that the response was acceptable

Example: Availability Scenario

Source: Database server hardware
Stimulus: Primary database server crashes
Artifact: Order processing system
Environment: Normal operation, peak hours
Response: System fails over to replica database
Response Measure: Less than 30 seconds downtime, no data loss
