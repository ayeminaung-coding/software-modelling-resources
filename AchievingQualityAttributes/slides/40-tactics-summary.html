Tactics Summary Matrix

Quality Attribute Primary Tactics Key Trade-offs
Availability Redundancy, fault detection, recovery, circuit breakers Cost, complexity, data consistency
Modifiability Encapsulation, loose coupling, cohesion, interfaces Performance overhead, initial complexity
Performance Caching, concurrency, scaling, load shedding Cost, complexity, consistency
Security Authentication, encryption, monitoring, least privilege Performance, usability, development time
Testability Dependency injection, observability, test doubles Development overhead, infrastructure cost
Usability UI separation, feedback, undo, design systems Development effort, maintenance

Common Tactic Combinations

  • Caching + CDN = Performance + Availability
  • mTLS + Zero Trust = Security + Modifiability
  • Feature Flags + Monitoring = Testability + Availability
  • Design System + i18n = Usability + Modifiability

Remember: Tactics are building blocks. Real architectures combine multiple tactics strategically. The art is in knowing which tactics to apply and when.
