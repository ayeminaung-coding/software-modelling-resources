Localize Modifications Tactics

Goal: Minimize the number of modules affected by a change

Tactic Description Example
Maintain Semantic Coherence Group related responsibilities together Single Responsibility Principle, bounded contexts
Abstract Common Services Create reusable services across modules Authentication service, logging framework
Generalize Modules Make behavior configurable via input Configuration files, feature flags
Limit Possible Options Constrain variation points Restrict plugin APIs, limit customization

Key Principle

When a change is needed, it should affect as few modules as possible. This is achieved by ensuring each module has a clear, focused purpose.
