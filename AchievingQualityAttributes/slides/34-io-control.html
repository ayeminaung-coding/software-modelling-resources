Input/Output Control Tactics

Enable control of inputs and observation of outputs for testing

Record/Playback

  • Capture real interactions
  • Replay for regression testing
  • VCR pattern for HTTP calls
  • Event sourcing for replay

Separate Interface from Implementation

  • Dependency injection
  • Interface-based design
  • Enable mock substitution
  • Inversion of Control (IoC)

Specialized Access Routes

  • Test harnesses at each layer
  • Debug endpoints (secured)
  • Feature flags for test modes
  • Sandbox environments

Test Doubles

  • Mocks: Verify interactions
  • Stubs: Provide canned responses
  • Fakes: Simplified implementations
  • Spies: Record calls for inspection

Modern Tools: Mockito/Jest (mocking) | WireMock (HTTP mocks) | Testcontainers (real dependencies) | Pact (contract testing) | LocalStack (AWS mocks)
