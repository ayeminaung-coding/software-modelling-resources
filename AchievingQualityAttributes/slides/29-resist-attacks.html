Resist Attacks Tactics

Prevent unauthorized access and protect system integrity

Tactic Description Modern Implementation
Authenticate Users Verify identity before access OAuth 2.0, MFA, Passkeys, Biometrics
Authorize Users Control what users can do RBAC, ABAC, OPA (Open Policy Agent)
Maintain Confidentiality Encrypt sensitive data TLS 1.3, AES-256, E2E encryption
Maintain Integrity Verify data not tampered Digital signatures, HMAC, checksums
Limit Exposure Minimize attack surface Least privilege, need-to-know access
Limit Access Network segmentation Firewalls, VPCs, Zero Trust Architecture

Zero Trust Architecture

  • "Never trust, always verify"
  • Verify every request, even internal
  • mTLS between all services
  • Continuous authentication

Secrets Management

  • Never hardcode credentials
  • HashiCorp Vault, AWS Secrets Manager
  • Rotate secrets regularly
  • Audit secret access
