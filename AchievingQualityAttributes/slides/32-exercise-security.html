Exercise: Design Security for Healthcare App

Security Architecture Design

Design security tactics for a HIPAA-compliant healthcare application

System Requirements

  • Doctors access patient records
  • Patients view their own records
  • Nurses update vital signs
  • Admins manage user accounts
  • External lab systems submit results

HIPAA Compliance

  • All access must be logged
  • Data encrypted at rest and in transit
  • Minimum necessary access principle
  • Breach notification within 72 hours
  • Regular security audits

1 Authentication Tactics

Consider: staff vs patient access, external systems

2 Authorization Model

Consider: role-based needs, emergency access scenarios

3 Detection Mechanisms

Consider: logging, monitoring, alerting

4 Confidentiality Controls

Consider: encryption types, data classification
