Tactic Control Model

Tactics are intended to control responses to stimuli

Stimulus

An event that triggers a response

e.g., Server crashes

→
Tactic

Design decision applied

e.g., Use redundancy

→
Response

Controlled system behavior

e.g., Failover to backup

The Goal

Tactics give architects control over how systems respond to events, ensuring quality attribute requirements are met.
