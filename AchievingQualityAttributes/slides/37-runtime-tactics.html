Runtime Usability Tactics

Support users during system operation

User Initiative Tactics

User controls the interaction

  • Undo: Reverse previous actions
  • Cancel: Abort in-progress operations
  • Pause/Resume: Control long operations
  • Aggregate: Combine commands (macros)

Modern Implementations

  • Command pattern for undo/redo
  • Event sourcing for full history
  • Optimistic updates with rollback
  • Cancelable async operations

System Initiative Tactics

System guides the user

  • Task Model: Track user workflow
  • User Model: Remember preferences
  • System Model: Show system status

Feedback Mechanisms

  • Progress indicators
  • Loading skeletons
  • Toast notifications
  • Inline validation
  • Contextual help

Perceived Performance: Users perceive systems as faster when they see immediate feedback. Skeleton screens and optimistic updates improve perceived performance even if actual latency is unchanged.
