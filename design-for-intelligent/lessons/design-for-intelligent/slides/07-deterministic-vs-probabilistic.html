Deterministic vs. Probabilistic

▶ Traditional Code
  • Same input → always same output
  • Can unit test with exact assertions
  • Bugs are reproducible
  • Behavior is fully specified
🤖 AI Component
  • Same input → probable output (not guaranteed)
  • Tests verify distributions, not exact values
  • Bugs may appear / disappear between runs
  • Behavior emerges from training data

This one difference changes how you design, test, deploy, and monitor the component.

Deterministic
if (amount > 500)
  return FLAGGED;
// always the same
Probabilistic
return model.predict(features);
// returns 0.73 (confidence)
// or 0.71 next time
