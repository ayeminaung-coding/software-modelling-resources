Constructor Injection (recommended):
class ExpenseProcessor {
  constructor(private fraudDetector: FraudDetector) {}

  submit(expense: Expense): SubmissionResult {
    var fraud = fraudDetector.evaluate(expense);
    if (fraud.isFraud && fraud.confidence > 0.8)
      reject(expense);
    // ...
  }
}

Constructor injection is testable: inject MockFraudDetector in tests. Factory and service locator are harder to test because dependencies are resolved at runtime.
