Pattern 5: RAG (Retrieval-Augmented Generation)

RAG Architecture Flow
SmartExpense Use Case

Policy compliance chatbot — employee asks "Can I expense a team dinner?" → retrieves relevant policy sections → LLM generates grounded answer with citation.

💡 RAG prevents LLM hallucination by grounding answers in your actual documents. The LLM can only reference what was retrieved. Key component: vector database (Pinecone, Weaviate, pgvector).
